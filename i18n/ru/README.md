**Превращает любого AI-агента в самообучающийся движок знаний.**

## Что это?

**AI Knowledge Engine** — набор модульных Markdown-инструкций, которые любой AI-агент может прочитать и выполнить, чтобы:

1. 🗂️ **Индексировать кодовую базу** — упаковать проект в один AI-читаемый контекстный файл (настройка за 5 минут)
2. 🧠 **Построить базу знаний** — создать полный Raw-First Knowledge Pipeline с NLP-обогащением, отслеживанием провенанса, самообучением и автоматическим обслуживанием

Без SaaS. Без API-ключей. Без облака. Всё работает локально на вашей машине.

> **Не привязан к индексатору:** Из коробки поддерживает [Repomix](https://github.com/yamadashy/repomix), но архитектура спроектирована для работы с любым инструментом контекстной индексации.

## Два режима

| Режим | Что получите | Время настройки |
|-------|-------------|----------------|
| **Lite** → `quick-start/` | Оптимизированный индекс кодовой базы с автообновлением по git commit | ~5 минут |
| **Full** → `knowledge-base/` | Персональный движок знаний с NLP, self-learning loop, очередью AI-ревью, проверками здоровья и умным расписанием | ~30 минут |

## Быстрый старт

### Lite: Индексация кодовой базы

```bash
# 1. Установить индексатор
npm install -g repomix

# 2. Скопировать quick-start/ в проект
cp -r quick-start/ /path/to/your-project/docs/ai-init/

# 3. Сказать AI-агенту:
"Прочитай docs/ai-init/INIT_GUIDE.md и настрой индексацию контекста для этого проекта"
```

### Full: База знаний

```bash
# 1. Установить зависимости
npm install -g repomix
pip install pyyaml python-slugify python-docx python-pptx pypdf pandas openpyxl
pip install spacy rake-nltk keybert
python3 -m spacy download ru_core_news_md

# 2. Скопировать knowledge-base/ в проект
cp -r knowledge-base/ /path/to/your-project/setup/

# 3. Сказать AI-агенту:
"Прочитай setup/knowledge-base/README.md и разверни базу знаний для [ваша роль]"
```

Агент задаст уточняющие вопросы о вашей роли, создаст структуру папок, настроит NLP-пайплайны и выполнит первую индексацию.

## Возможности

### Lite режим
- 📦 **Настройка одной командой** — AI-агент сам всё сконфигурирует
- 🔄 **Автообновление** — Git hooks пересоздают контекст при каждом коммите
- 🎯 **Осведомлённость о стеке** — готовые паттерны для React, Rust, Python, Go, Node.js
- 🔒 **Сканирование безопасности** — обнаружение утечек секретов перед индексацией
- 📊 **Контроль бюджета токенов** — Tree-sitter сжатие уменьшает расход на 50-70%

### Full режим
- 🔬 **Raw-First Pipeline** — кидаете PDF, DOCX, PPTX в `raw/` → автоконвертация в Markdown → NLP-обогащение → чистые знания
- 🧠 **Self-Learning Loop** — `!save` для фиксации сессий, `!reflect` для синтеза инсайтов, `!audit` для полного ревью
- 🔗 **Перекрёстные связи** — `[[wikilinks]]` + routing tables для навигации по сотням страниц
- 📊 **NLP-обогащение** — NER, извлечение ключевых слов, entity resolution (spaCy + KeyBERT) — 0 токенов, чистый CPU
- 📜 **Отслеживание провенанса** — каждый факт прослеживается до источника с хеш-верификацией
- 🔍 **Surprise Filter** — антидубликация: только действительно новая информация попадает в базу
- ⚕️ **Проверки здоровья** — Python-линтер для устаревших страниц, сирот, битых ссылок (+ `--metrics` для health-метрик)
- ⏰ **Умное расписание** — авторефлексия при достижении порога важности; пропускает пустые периоды
- 🔐 **Приватность по умолчанию** — сырые данные и ревью никогда не индексируются
- 🌍 **Полная портабельность** — чистые Markdown-файлы, никаких БД, серверов, работает на любой машине
- 🔧 **Reference-реализации** — Python и shell скрипты копируются и используются «как есть», без изобретения с нуля
- ⬆️ **Upgrade-механизм** — `kb_upgrade.py` обновляет развёрнутую базу с детекцией customizations

## Архитектура

```
                    ┌─────────────┐
Пользователь ─────→ │   raw/      │  ← PDF, DOCX, заметки, чаты
                    └──────┬──────┘
                           │ kb_ingest.py (Python + NLP)
                           ▼
                    ┌─────────────┐
                    │ processed/  │  ← Markdown + NLP-метаданные (0 токенов)
                    └──────┬──────┘
                           │
              ┌────────────┼────────────┐
              ▼            ▼            ▼
        ┌──────────┐ ┌──────────┐ ┌──────────┐
        │knowledge/│ │ review/  │ │ assets/  │
        │ (чистое) │ │(сложное) │ │(бинарное)│
        └────┬─────┘ └──────────┘ └──────────┘
             │
             ▼ индексатор контекста
        ┌──────────────┐
        │  output.xml  │  ← Готовый контекст для AI
        └──────────────┘
```

### Модель стоимости

Расход токенов зависит от **режима работы** (`mode` в `kb.config.yml`):

| Уровень | Операции | default | super |
|---------|---------|---------:|------:|
| **Python (бесплатно)** | NLP, lint L1, конвертация | 0 tok | 0 tok |
| **Лёгкий AI** | Оценка важности | ~500 | ~1-2K |
| **Переключаемый** | Surprise filter, аннотации, entity resolution | 0 tok (Python) | ~3-9K tok (AI) |
| **Тяжёлый AI** | Рефлексия, глубокое ревью, writeback | ~15-100K | ~15-100K |

| Режим | В день (активно) | В неделю |
|------|-------------------:|----------:|
| `default` | **~3-4K токенов** | ~20-30K |
| `super` | **~50-200K+ токенов** | ~500K-1.5M |

## Команды пользователя

Команды, которые вы говорите AI-агенту в чате IDE:

| Команда | Что делает | Стоимость |
|---------|-----------|----------|
| `!save` | Сохранить summary сессии | ~2K токенов |
| `!reflect` | Синтезировать higher-level insights | ~15K токенов |
| `!audit` | Полный AI-ревью базы | ~50–100K токенов |
| `!super` | Переключить режим: default ↔ super | 0 токенов |
| `!super on/off` | Явно включить/выключить super mode | 0 токенов |
| `!super status` | Показать текущий режим | 0 токенов |

### Операционные режимы

Система поддерживает два режима, переключаемых командой `!super`:

| Режим | Парадигма | Токены/день | Лучше для |
|-------|-----------|------------|----------|
| **default** | Python-first, throttled | ~3-4K | Ограниченный бюджет, ежедневная работа |
| **super** | AI-first, on-demand | ~50-200K+ | Безлимитный план, интенсивное накопление |

**Default** использует Python (NLP, эвристики) для surprise filter, аннотаций и entity resolution. AI вызывается только для оценки важности.

**Super** заменяет Python-эвристики на AI-анализ:
- 🔍 **Семантический surprise** — AI оценивает каждый материал (+40% точности vs NLP overlap)
- 📝 **Содержательные аннотации** — AI генерирует связи с предложениями правок (+60%)
- ⚡ **On-demand рефлексия** — после каждого значимого ingest (importance ≥5)
- 🧪 **Ежедневный AI-аудит** — Lint L2 автоматически при консолидации
- 📥 **Авто-обработка review** — без ожидания `!audit`

> ⚠️ **Super mode** может исчерпать дневной лимит токенов за одну сессию. Используйте только с безлимитными планами.

### Умные триггеры

Система отслеживает **importance score** каждого элемента. Когда сумма превышает порог (default: 25, super: 5), рефлексия запускается автоматически.

## Модули инструкций

15 модулей, которые AI-агент читает последовательно:

| # | Модуль | Назначение |
|---|--------|-----------|
| 00 | Overview | Карта развёртывания: что читать, что копировать (read first) |
| 01 | Prerequisites | Проверка окружения |
| 02 | Init | Уточнение роли, создание структуры |
| 03 | Pipeline | Python-скрипт ingest: конвертация + NLP + хеширование |
| 04 | Review | Workflow AI-ревью сложных материалов |
| 05 | Index | Индексация, `[[wikilinks]]`, routing tables |
| 06 | Agents Template | Шаблон `AGENTS.md` с бюджетом токенов |
| 07 | Interaction Loop | Self-learning + session capture + writeback |
| 08 | Portable | Портабельность + Dynamic Context Enrichment |
| 09 | Lint | Health-check: Level 1 (Python) + Level 2 (AI) + `--metrics` |
| 10 | Log | Append-only хронология операций |
| 11 | Provenance | Source hash, span-level citations, regression tests |
| 12 | NLP Preprocess | NER + keyword extraction + entity resolution |
| 13 | Autorun | File watcher, git hooks, умное расписание |
| 14 | Initial Population | Генерация role-specific `DATA_PLACEMENT_EXAMPLES.md` |
